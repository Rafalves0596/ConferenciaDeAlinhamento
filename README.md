# Conferência de Alinhamento
Membro do Projeto: Rafael, Hércules, Vinícius e Lucas.

## 1 - Contextualização
Durante o impressão de uma impressora 3D, é comum que a mesa de impressão se desalinhe devido a vibração excessiva da máquina, causando o desperdício de matéria-prima e impressões defeituosas. Afim de evitar isto, a ideia deste repositório é apresentar o desenvolvimento de um sistema que confere constantemente o alinhamento da mesa, apresentando linhas de raciocínio, componetes usados, e os códigos do sistema.
