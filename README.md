# Conferência de Alinhamento
Membro do Projeto: Rafael, Hércules, Vinícius e Lucas.

## 1. Contextualização
Durante o impressão de uma impressora 3D, é comum que a mesa de impressão se desalinhe devido a vibração excessiva da máquina, causando o desperdício de matéria-prima e impressões defeituosas. Afim de evitar isto, a ideia deste repositório é apresentar o desenvolvimento de um sistema que confere constantemente o alinhamento da mesa, apresentando linhas de raciocínio e componetes usados.

## 2. Fluxo Lógico
Considerando a problemática do alinhamento, é necessário que o sistema possua sensores capazes de identificar o erro e motores para mover e corrigir o defeito. Com isso, é possível considerar o uso de sensores de luminosidade para identificar o desalinhamento da mesa de impressão pela pouca ou muita luminosidade que chefga ao sensor.

## 3. Componentes 
Para os componentes, usamos: 
- 2 Sensores de Luminosidade;
- 2 Servo Motores;
- 1 Arduino Uno;
- 1 Placa Shield.
